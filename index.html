CRAFT-W / WRIST MANIPULATION

A wrist in motion.

倾倒、挥锤、扫桌面。以腕部动作完成末端朝向调整、出料和短行程接触。

三段视频均为原速脚本仿真，采用固定支撑和理想刚性握持。倾倒使用颗粒代理。挥锤和倾倒场景中的 CR3 保持固定，腕部采用暂定 ±15° 的双轴串联近似。

URDF & demo launchers ↗ Integration guide ↗
Run the model and demos locally

Clone the CRAFT-W repository and use Python 3.12. In the viewer, expand Control to adjust the 17 independent joint angles.

python -m pip install -r requirements-viewer.txt
python scripts/launch_demo.py wrist --interactive
python scripts/launch_demo.py cup-pour
python scripts/launch_demo.py hammer-nail
python scripts/launch_demo.py brush-sweep

DUMMY V2 / MODEL & CONTROL INTERFACE

From URDF
to control.

基于 Dummy V2 平台，连接机械臂描述、夹爪与相机模型，以及本地网页上位机。当前默认装配包含夹爪、深度相机和支架。

  • 保留 CAD 颜色的 URDF 与 STL 视觉模型。
  • 关节目标、笛卡尔 FK/IK、可拖动目标与未来位姿预览。
  • 示教录放、标定界面和模型参数管理。
  • 重力补偿、参数辨识与柔顺控制实验。

图片来自当前模型的 mock 会话。J1–J5 控制机械臂姿态，J6 驱动夹爪，相机随 J5 运动。HostApp 源码目前维护在本地，硬件功能仍在验证中。
