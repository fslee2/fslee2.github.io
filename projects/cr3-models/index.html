Overview

The collection packages the arm geometry and coordinate frames for reuse across simulation and control projects. The rotating view shows the mounted CR3 arm and CRAFT Hand from multiple angles.

Using the models

The repository includes self-contained MuJoCo scene files, ROS 2 URDF and Xacro descriptions, and meshes. Start with the reach-debug scene to inspect the assembled model, or use the ROS 2 description for motion-planning integration.
