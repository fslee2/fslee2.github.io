Overview

This course project follows a battery pack through production planning, process execution, inventory, and quality checks. The dashboard brings records from those stages into one manufacturing execution system.

Application

The Vue 3 interface reads production and quality records through a Spring Boot backend backed by MySQL. The dashboard screenshot can be opened at full resolution to inspect the layout and available operations.
